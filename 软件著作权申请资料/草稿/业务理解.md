# 业务理解

- 软件名称：服务可用性监控系统
- 产品定位：面向网站、网络服务和应用组件的自托管可用性监控软件，通过浏览器管理监控项目并查看检查历史。
- 面向领域 / 行业：信息技术运维与网络服务监控
- 核心价值：集中检查多个服务的可达状态，保留历史结果，并以监控列表和状态页呈现运行情况。
- 证据文件：`业务理解证据.md`

## 目标用户

- 网站和应用管理员
- 运维人员
- 管理自托管服务的个人或团队

## 主要业务功能

- 多类型监控
- 周期检查与独立间隔
- 监控列表管理
- 历史数据与事件
- 只读状态页

## 功能说明

- 多类型监控：支持 HTTP 内容、网络传输、数据库、消息队列以及应用健康端点等 100 类检查；不同类型可填写相应目标与校验条件。
- 周期检查与独立间隔：全局间隔用于默认检查和页面刷新；单个监控可设置自己的检查间隔、手动检查、暂停或恢复。
- 监控列表管理：以列表或卡片展示监控结果，可按名称、地址、类型搜索，并按状态或类型筛选、排序和分页。
- 历史数据与事件：本地保存心跳、异常与恢复事件；支持 JSON 历史记录导入、去重及历史数据导出。
- 只读状态页：状态页展示服务状态、检查记录和在线率，提供搜索筛选与分页，用于查看而不提供修改监控的操作。

## 典型操作流程

1. 启动服务并打开管理控制台
2. 设置全局间隔并创建监控项目
3. 查看自动检查结果，按需筛选、手动检查或调整单项间隔
4. 查看事件时间线和状态页
5. 按需要导入或导出历史记录

## 操作手册页面/流程模块

1. 管理控制台与监控列表：启动服务后在浏览器打开管理控制台首页。
   - 使用场景：服务项目较多时，管理人员需要查找特定目标并比较最近检查情况。
   - 操作要点：在搜索框输入名称、地址或类型，或选择状态和类型筛选。；选择排序方式、列表或卡片视图，并使用每页数量和翻页按钮浏览。；在监控行展开详情，查看检查消息、间隔及近期统计。
2. 新增监控项目：在管理控制台点击新增监控。
   - 使用场景：需要监控一个新网站、数据库或应用服务时使用。
   - 操作要点：填写名称，选择监控类型并输入目标。；根据所选类型填写关键字、状态码、DNS 记录或其他条件。；按需取消使用全局间隔并填写单独间隔，填写超时后创建。
3. 调整检查间隔和管理单项：在控制台顶部使用全局间隔，在目标监控项目的操作区使用相应按钮。
   - 使用场景：某项服务需要单独检查频率，或需要临时停止检查时使用。
   - 操作要点：选择全局间隔，跟随全局的项目以及页面刷新使用该设置。；使用改间隔输入单项秒数；留空可恢复全局间隔。；按需立即检查、暂停或恢复；删除时确认删除提示。
4. 历史导入、导出与事件：在控制台打开导入弹窗或点击导出；展开事件时间线查看事件。
   - 使用场景：迁移已有监控记录或检查某项服务的异常变化时使用。
   - 操作要点：将符合格式的 JSON 记录粘贴到导入框并提交。；查看导入结果中的新增、重复及拒绝数量。；按需导出全部历史，或展开事件时间线查看异常与恢复。
5. 只读状态页：从管理控制台点击状态页，或访问状态页地址。
   - 使用场景：需要浏览服务总体情况而不修改监控设置时使用。
   - 操作要点：查看总数、在线、异常和平均延迟。；通过搜索、筛选和分页定位服务，展开项目详情查看检查结果。；展开事件时间线查看异常与恢复记录。
